HOW IT WORKS

让协作有路由，
让结果有证据。

01

显式选择

从 Web UI 选择一个、多个或全部 Agent；正文里的自然语言 @ 不会偷偷触发新回合。

02

结构化执行

Codex App Server、ACP session 与 Claude Code stream-json 保持原生会话，Broker 统一管理路由、取消与恢复。

03

持久化证据

最终回复、Turn 状态、推理与工具记录按数据类型落盘，刷新后仍可回放和审计。
